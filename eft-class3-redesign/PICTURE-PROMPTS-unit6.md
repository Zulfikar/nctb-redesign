**How to use this file:**
1. Give ChatGPT section 1 once.
2. Make the new reference sheet (section 2) first and keep it. Upload the sheets that each picture names, every time you ask for that picture.
3. Then make the pictures (sections 3–7), one at a time.
4. Save each picture in `~/Downloads/eft-class3-redesign/art/new/` under its file name (for example `u6-l1-friends.png`). The build uses a new picture as soon as it's there, instead of the old one.
5. Tell Claude. Claude checks each picture against its prompt and rebuilds. **This unit has no speech bubbles**, so no picture needs calm space for one.

**How the page shows them:** small boxes that trim the edges of a picture (for example 41 × 18 mm for a washing step). So in every picture, **keep the important part in the middle**, with a little plain space around it.

**Speech bubbles are added later by us.** When I ask for space for bubbles, keep that part of the picture calm (plain sky, wall or blackboard) with no faces in it. Don't draw any bubbles yourself.
