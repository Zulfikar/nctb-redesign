# Class 3 Math (NCTB প্রাথমিক গণিত, তৃতীয় শ্রেণি, Bangla version): chapters 10–13, page by page

Source: `~/Downloads/Class-3, Math BV. combine _compressed.pdf` (no text layer). Every page below (printed 107–155, PDF 113–161) was rendered and read as an image. Small digits, coins, notes, clock hands and dials were checked at 300–600 dpi.

Conventions in this file:
- **All numbers are ASCII digits**, also inside quoted Bangla (the book prints Bangla digits). Money is written `65.75` only in my own notes; quotes keep the book's "65 টাকা 75 পয়সা" form.
- `□` is an empty answer box in the book. `___` is a blank line.
- **Ans:** is my answer (the book leaves it blank). **Printed:** the book shows the answer.
- (?) marks a doubtful reading.
- Markers as in chapter 9: **মূল প্রশ্ন** (? bubble), **কাজ** (pink triangle), **অনুশীলন** (teal square, written "অনু"), **নিজে করি** (blue circle, written "নিজে"). Numbering of কাজ/অনুশীলন restarts after each মূল প্রশ্ন, exactly as printed.
- Each exercise ends with a **Fit:** line:
  - **[as is] Type**: an existing type can carry it unchanged.
  - **[add A#] Type**: needs a small addition to an existing type (list in §6).
  - **[new N#]**: needs a new type (list in §6).
  - **[skip]**: real-world measuring, discussion, free drawing or a project. Not a game as printed.
  - **[demo]**: worked example with the answer printed. Usable as a first, shown-answer round.

**Offset checked: PDF page = printed page + 6** (printed 107 = PDF 113; printed 155 = PDF 161, "- সমাপ্ত -").

  - Word problems often have two steps (p117 নিজে ৫: add, then take from 200).
- **A2 Taka Shop: পয়সা.**
  - Coins 5, 10, 25, 50 পয়সা (1 পয়সা optional).

## 8. Surprises and book errors

1. **p131 নিজে ১(10) has no correct option.** The options are 60 / 120 / 240 / 1440; the answer is 24. p128 কাজ ৫(7) offers "24 বার". It also misprints "ঘরির" for ঘড়ির.

3. **p130 নিজে ১(5) has three options that add up to 3 kg 220 g** (ক, খ, ঘ). Only ক avoids a "3 কেজি" weight, but 2 কেজি is not in the book's own weight set either.
4. **p141 অনু ২ says "4টি চিত্রের" but prints 3 figures.**
