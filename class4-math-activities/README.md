Printed page = PDF page − 7 (printed p.1 is PDF p.8). Game rounds carry **no answers**: the server works every one out on import (`validate.js` checks it equals ours, which is the book's where it prints one).

## Importing it

1. **Deploy first** the website and server with part A (the new rounds: long division, factors and primes, mixed numbers, dates, the protractor, lines and triangles…). On a server without them, the import drops those rounds.
2. **Check the codes are still free** (read-only): `node tools/codes-live.js` (24 Nov: all 255 free; /b/KZT9KF had 0 activities).
3. **Import** into /b/KZT9KF (Activity Studio → the book → Import, as with Class 3). The 11 chapters come with it; every game arrives as a draft.
4. **Publish** (per chapter: "Publish all"), then **Replace PDF** with `../class4-math-redesign/class4-math-book.pdf` (the one with the page QRs).
5. **Android:** the app plays the new rounds only after its port (not done yet); iPhone plays them in its web view.
